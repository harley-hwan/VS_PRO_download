Microsoft Visual Studio 2010 평가판을 사용해 주셔서 감사합니다.

평가판은 30일간 유효합니다.  Visual Studio 2010의 평가 기간을 온라인 등록을 통해 90일로 연장하거나 유효한 제품 키를 사용하여 설치를 전체 라이선스 버전으로 전환할 수 있습니다.  정품의 제품 키는 설치 미디어의 DVD 케이스에서 찾을 수 있습니다.

참고: Visual Studio 2010 시험판 버전의 경우 전체 라이선스 버전으로 전환할 수 없습니다.  공식 릴리즈를 설치하기 전에 모든 Visual Studio 2010 시험판을 제거해야 합니다.

Visual Studio 2010 구입

Visual Studio 2010을 구매하려면 소매점에서 제품을 구입하거나여기를 클릭하여 온라인으로 제품 키를 주문하십시오.

정품 인증

다음 중 한 가지 방법으로 제품의 정품 인증을 받을 수 있습니다.
  • Microsoft Visual Studio 2010 설치 프로그램의 유지 관리 페이지
    1. [시작] 메뉴(Start+R)에서 실행을 클릭하고 2단계로 진행하거나 Visual Studio 설치 미디어에서 setup.exe를 실행하고 5단계로 진행하십시오.
    2. control appwiz.cpl을 입력하고 확인을 누르십시오.
    3. Microsoft Visual Studio 2010(Professional, Premium, Ultimate 등)을 선택하십시오.
    4. 유지 관리 모드에서 Visual Studio 2010 설치 프로그램을 시작하려면 변경을 클릭하십시오.
    5. 정품 인증을 클릭하십시오.
  • Microsoft Visual Studio 2010 도움말 정보 페이지
    1. Microsoft Visual Studio 2010을 시작합니다.
    2. 제품의 [도움말] 메뉴에서 Microsoft Visual Studio 정보를 클릭하십시오.
    3. Microsoft Visual Studio 2010 정품 인증 대화 상자를 시작하려면 업그레이드를 클릭하십시오.
  • Microsoft Visual Studio 2010 정품 인증 대화 상자
    1. 제품 키 프롬프트에 올바른 새 키를 입력하십시오.
    2. 정품 인증을 클릭하십시오.
