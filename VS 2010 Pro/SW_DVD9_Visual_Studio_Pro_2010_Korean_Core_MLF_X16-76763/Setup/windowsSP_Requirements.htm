Microsoft Visual Studio 2010

지원되는 운영 체제 서비스 수준:

  • Windows XP 서비스 팩 3
  • Windows Server 2003 서비스 팩 2
  • Windows Vista 서비스 팩 2
  • Windows Server 2008 서비스 팩 2
  • Windows Server 2008 R2
  • Windows 7

Visual Studio를 설치하려면 컴퓨터에 최소한 지원되는 Windows 서비스 팩이 먼저 설치되어 있어야 합니다. Windows 서비스 팩은 http://windowsupdate.microsoft.com에서 다운로드하여 설치할 수 있습니다.  서비스 팩을 설치하고 나면 컴퓨터를 다시 시작해야 합니다.  Visual Studio 설치 프로그램은 자동으로 다시 시작되지 않습니다.  Visual Studio 설치 프로그램을 다시 시작하려면 원래 설치 미디어에서 setup.exe를 두 번 클릭하거나 다운로드 웹 사이트에서 해당하는 링크를 클릭하십시오.

참고:  http://windowsupdate.microsoft.com에서 사용할 수 있는 운영 체제에 대한 업데이트를 정기적으로 확인하고 설치하는 것이 좋습니다.

서비스 팩을 설치하는 이유

서비스 팩은 제품 업데이트 분산을 위한 수단입니다.  서비스 팩에는 시스템 안정성, 프로그램 호환성, 보안 등의 향상을 위한 업데이트가 포함될 수 있습니다.  Microsoft 서비스 팩에 대한 자세한 내용은 다음을 참조하십시오. http://support.microsoft.com/efault.aspx?scid=fh;KO-KR;sp.
